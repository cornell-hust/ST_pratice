## 汇报稿改后的自查方式

改完 `成果汇报.pptx` 想确认版式没崩，可用 WPS 的 COM 接口把任意页导出成 PNG 看图：

```powershell
$app = New-Object -ComObject KWPP.Application
$pres = $app.Presentations.Open("<pptx 绝对路径>", $true, $false, $false)
$pres.Slides.Item(14).Export("<输出目录>\slide14.png", "PNG", 1920, 1080)
$pres.Close(); $app.Quit()
```

制作约定沿用模块一：python-pptx 生成、学校 PPT 母版、视频 1080p。
