# ST_pratice 项目结构说明

> 本文档是项目的结构导航与目录约定，供小组成员和课程审查使用。
> 整理日期：2026-09-10。本次结构调整**只新增文件，未删除、未修改任何现有文件**；需要移动或清理的内容统一列入第 7 节"待确认调整清单"，经小组确认后再执行。

## 1. 项目概况

- 项目：软件测试与质量保证实践课程小组作业（研究生课程）。
- 模块一（已交付）：对开源库 croniter 6.2.2 的测试基础实践——用例设计（40 条清单用例，原 5 条专项检查已并入账本，重复与冗余用例已去重）、三个历史缺陷的复现与修复、自动化测试与覆盖率统计。
- 模块二（进行中）：AI 融合实践，目录规划见 [module2/README.md](../module2/README.md)，课程要求要点见《课程录音总结.md》。
- 交付物与课程附录的对应：附录一→`module1/testcases/`，附录二→`module1/defects/`，附录三→`module1/reports/`，附录四→`module2/reports/`（预留）。

## 6. 文档与版本约定

- 过程文档放各模块 `docs/`；正式交付只放对应交付目录（testcases/defects/reports）。
- 版本管理优先"原位更新 + 注明更新日期"；确需并存时加 `v2` 后缀，并在文首说明与旧版的差异和现行版本。
- 任何新目录都要带 README 说明职责；新增文件后同步登记到本文件的文件地图。
