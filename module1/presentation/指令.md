```python
from datetime import datetime
```

```python
from croniter import croniter, croniter_range
```

### 解析 — 构造迭代器

```python
it = croniter('*/5 * * * *', datetime(2024, 1, 1, 12, 0))
```

### 解析 — 算下一次触发时间

```python
it.get_next(datetime)
```

### 迭代 — 在同一个对象上继续取

```python
it.get_next(datetime)
```

### 迭代 — 反向取上一次

```python
croniter('0 9 * * 1-5', datetime(2024, 1, 3, 12, 0)).get_prev(datetime)
```

### 范围 — 窗口内全部触发点

```python
list(croniter_range(datetime(2024, 1, 1), datetime(2024, 1, 1, 1, 0), '*/20 * * * *'))
```

### 匹配 — 命中

```python
croniter.match('0 0 * * 1', datetime(2024, 1, 1))
```

### 匹配 — 未命中

```python
croniter.match('0 0 * * 1', datetime(2024, 1, 2))
```

### 匹配 — 时间段内有没有触发点

```python
croniter.match_range('*/15 * * * *', datetime(2024, 1, 1, 10, 0), datetime(2024, 1, 1, 10, 31))
```

### 校验 — 合法表达式

```python
croniter.is_valid('*/5 * * * *')
```

### 校验 — 非法表达式

```python
croniter.is_valid('0 0 32 * *')
```

### 校验 — 非法表达式直接构造会抛标准异常

```python
croniter('0 0 32 * *', datetime(2024, 1, 1))
```
